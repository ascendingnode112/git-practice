# Git Fundamentals Resources

## Knowledge

- [Book: _Pro Git_ (2nd ed.) — Scott Chacon & Ben Straub](https://git-scm.com/book/en/v2)
  The canonical Git book, free online, maintained by the Git project itself. Use for: any core concept — snapshots, the three areas, branching, merging. Chapters 1–3 cover this whole mission.
- [Reference: Official Git documentation](https://git-scm.com/docs)
  Man pages for every command. Use for: exact flag behavior when a lesson's simplified version isn't enough.
- [Article: "The Git Parable" — Tom Preston-Werner](https://tom.preston-werner.com/2009/05/19/the-git-parable.html)
  A story that derives Git's design from first principles. Use for: building the snapshot mental model — why Git works the way it does.
- [Interactive: Learn Git Branching](https://learngitbranching.js.org/)
  Visual, sandboxed branching simulator. Use for: practicing branch/merge/rebase moves and *seeing* the commit graph change.
- [Site: "Oh Shit, Git!?!" — Katie Sylor-Miller](https://ohshitgit.com/)
  Plain-language recovery recipes. Use for: the "I broke something" moments — maps directly to the mission's recovery goal.
- [Blog: Julia Evans on Git — jvns.ca](https://jvns.ca/#git)
  Short, precise posts on the confusing corners (HEAD, detached HEAD, what's in a commit). Use for: filling conceptual gaps as they show up.

- [Docs: "About remote repositories" — GitHub Docs](https://docs.github.com/en/get-started/getting-started-with-git/about-remote-repositories)
  Official, short. Use for: what a remote is, URL forms, how clone/push/pull relate to it.
- [Docs: "About pull requests" — GitHub Docs](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests)
  Official definition of the PR mechanism. Use for: what a PR is and isn't, before any workflow opinions.
- [Book: _Pro Git_ §2.5 "Working with Remotes"](https://git-scm.com/book/en/v2/Git-Basics-Working-with-Remotes)
  The remote commands from the source. Use for: remote add/rename, fetch vs pull, tracking branches.
- [Interactive: GitHub Skills — "Introduction to GitHub"](https://skills.github.com/)
  Official hands-on courses run inside real repos via PRs. Use for: guided practice of the full PR loop.

## Wisdom (Communities)

- [Stack Overflow — `git` tag](https://stackoverflow.com/questions/tagged/git)
  Highest-volume Git Q&A on the internet. Use for: checking whether a confusing behavior is a known pattern before assuming you did it wrong.
- [r/git](https://www.reddit.com/r/git/)
  Smaller but focused. Use for: workflow-opinion questions ("is it normal to…") where there's no single right answer.
- Radian engineering team (internal)
  Chris leads engineers who use Git daily. Use for: real code review and repo conventions once fundamentals are in place — the best feedback loop available.
