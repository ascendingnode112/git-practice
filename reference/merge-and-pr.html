Merge & Pull Request

Reference · git-practice

The one-sentence model

A pull request is a proposal to merge one branch into another, tracked live against the source branch; merging it moves the target branch's pointer forward to a new merge commit — a snapshot with two parents.

Sources: GitHub Docs, "About pull requests" · Pro Git §3.2

PR lifecycle

StageWhat's true
OpenThe PR tracks the source branch. Push more commits to the branch and the PR updates automatically — it is not frozen at creation time.
ReviewDiscussion, comments, and approvals attach to the PR on GitHub. Git itself knows nothing about any of this.
MergedGitHub creates the merge on the remote. The target branch's pointer moves there; the source branch pointer stays put and is usually deleted afterward.

What merging moves (and what it doesn't)

PointerAt PR merge
Remote main (on GitHub)Moves to the new merge commit immediately.
Remote add-notes (on GitHub)Stays put. Merging never moves the source branch.
Local main, local origin/mainMove nothing until you fetch/pull — your machine hasn't heard the news. git status will even claim "up to date" because it compares against the stale record.

Core commands

CommandWhat it actually does
gh pr view [--web]Shows the open PR for the current branch — commits, files changed, discussion.
gh pr merge --mergeMerges the PR with a merge commit (same as the green button; --web if you prefer the button).
git pullOn main after a PR merge: fetches the news and fast-forwards local main up to the merge commit.
git log --oneline --graphShows the merge as a diamond: the merge commit with two parent lines.
git branch -d <name>Safe cleanup of a merged branch — deletes the label, refuses if work would be stranded.
git fetch --pruneDrops remote-tracking records for branches deleted on the remote.

Facts that prevent confusion later

FactWhy it matters
A merge commit has two parents.It joins two histories; log --graph draws it as a diamond. Every other commit has one parent (the root has none).
Merging doesn't destroy the source branch's commits.They're now reachable from main too. Deleting the branch afterward removes only the label.
"Up to date" means up to date with your record.git status never checks the network. After anything happens on GitHub, fetch before trusting it.
GitHub offers three merge methods.Merge commit (default, used here), squash, and rebase — the other two rewrite history and come later, if ever.
