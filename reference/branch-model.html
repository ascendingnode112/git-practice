The Branch Model

Reference · git-practice

The one-sentence model

A branch is a movable pointer to one commit — a 41-byte file containing a hash. HEAD points to whichever branch you're on, and committing moves that branch forward.

Source: Pro Git §3.1, "Branches in a Nutshell"

Arrows point parent-ward: each commit stores its parent's hash. One history, several pointers into it.

The three kinds of pointer

PointerWhat it is
Branch (main, add-notes)A movable label on one commit. Committing while on it moves it forward; nothing else does.
HEADPoints at the branch you're on — "you are here." Switching branches repoints HEAD and rewrites your working directory to match.
Remote-tracking (origin/main)Your local, read-only record of where a branch was on the remote at last contact (fetch/push). Not live — it does not move until you talk to the remote.

Core commands

CommandWhat it actually does
git branch -vLists local branches and the commit each points at. -a adds remote-tracking ones.
git switch <branch>Repoints HEAD and rewrites the working directory to that branch's snapshot.
git switch -c <name>Creates a new branch at the current commit and switches to it. Cheap: writes one 41-byte file.
git log --oneline --all --graphDraws the whole commit graph with every pointer labeled. The map view.
git branch -d <name>Deletes the pointer (not the commits). Refuses if unmerged work would be stranded.

Facts that prevent confusion later

FactWhy it matters
Branches are labels, not containers.Commits aren't "in" a branch; a branch is a pointer, and its history is whatever is reachable parent-ward from it.
Switching rewrites your files.Files tracked only on another branch vanish from disk and reappear when you switch back. Nothing is lost — snapshots are permanent.
main and origin/main are different pointers.One is your local branch; the other is your last-known record of the remote's. They drift apart until you fetch/push/pull.
Creating a branch copies nothing.No duplicate files, no new snapshot — just a new 41-byte pointer file. Branch freely.
